# three-alembic

three.js rendering of Alembic (`.abc`) files. Animated files play with `WebGPURenderer` (TSL).

- `ABCLoader` - loads `.abc` files into three.js objects. `loader.load( url, onLoad, onProgress, onError )` and `loader.loadAsync( url )` give a `Group` with the objects of the file, or an `ABCAnimation` if the file is animated. `loader.parse( source )` reads the bytes of a file (`Uint8Array` or `ArrayBuffer`), or an `AlembicReader` (read once, then parse it again for other frames).
- Transforms become a `Group`, meshes a `Mesh` with `MeshStandardMaterial`, and points `Points` with `PointsMaterial`. Other objects become a `Group`, with their children. Each object has `name`, and `userData.fullName` (path), `userData.metadata` and `userData.schema` (`'Xform'`, `'PolyMesh'`, `'Points'` or `null`).
- `loader.setOptions({ sampleIndex, time, timeMode, textureMemory })` selects the frame. `sampleIndex` is the frame number (default `0`). `time` is the time in seconds, and it is used instead of `sampleIndex` when set. `timeMode` is `'floor'` (default), `'ceil'` or `'nearest'`. For an animated file, `time` or `sampleIndex` gives the start time of the animation. `textureMemory` is the most GPU memory, in bytes, for the animation of one mesh or points object (default 256 MB). A larger animation loads its frames while it plays.
- `ABCAnimation` - a `Group` that plays an animated file, as `FrameVolumeAnimation` of `three-openvdb`. `animation.play()`, `pause()` and `stop()` control the playback. Call `animation.update( delta )` on each frame, with `delta` in seconds. `time` (in seconds, from `startTime` to `endTime`), `speed` (default `1`, negative values play backwards), `loop` (default `true`) and `frame` (`0` to `totalFrames - 1`) can be changed at any time. `fps` is `speed` multiplied by the frame rate of the file. `animation.dispose()` frees the geometries, materials and textures.
- Each object of an `ABCAnimation` plays with the times of its own frames. Transforms, and meshes and points that keep the same vertices, move smoothly from frame to frame. These meshes and points get a material made with `createVertexAnimationMaterial`. Meshes and points whose vertices change get a new geometry at each frame. The next frames are made while the animation plays. If a frame is not ready in time, the last frame stays on screen, and the animation keeps its time.
- `createVertexAnimationMaterial( material )` - gives a material that shows the animation of `ABCAnimation` objects, with lights and shadows. Use it to show an animated file with other materials, for example `mesh.material = createVertexAnimationMaterial( new MeshPhysicalMaterial() )`. A node material (`three/webgpu`) is changed and given back. Other materials are copied into a new node material. One material can be used by many objects, also by objects that are not animated. Normal maps are not used on animated meshes.
- `WABCLoader` - loads `.wabc` files (made by the `wabc` CLI), as `ABCLoader` loads `.abc` files. `loader.load( url, onLoad, onProgress, onError )`, `loader.loadAsync( url )` and `loader.parse( source )` (the bytes of a file, or a `WabcFile`) give a `Group`, or a `WABCAnimation` if the file is animated. Normals that the file does not store are made at load.
- `WABCAnimation` - plays an animated `.wabc` file, with the same members as `ABCAnimation`: `play()`, `pause()`, `stop()`, `update( delta )`, `time`, `speed`, `loop`, `frame`, `totalFrames`, `dispose()`. A new frame is shown when it is read; until then the last frame stays on screen.
